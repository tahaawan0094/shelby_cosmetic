# Timeless Beauty — Next.js starter

This workspace contains a minimal Next.js + Tailwind + Framer Motion scaffold with a Sanity client helper. It implements a homepage with a navbar and hero section similar to the provided design.

Quick setup:

1. Install dependencies

```bash
npm install
```

2. Add images to `public/images/` — at minimum `hero.jpg`, `product1.jpg`, `product2.jpg`.

3. Add images to `public/images/` — at minimum `hero.jpg`, `product1.jpg`, `product2.jpg`.

4. Run dev server

```bash
npm run dev
```
